
Practical Biostatistics: Linear Regression Using Clinical Data

Objective: Build a multiple linear regression model using sample clinical data, evaluate predictor relationships, and assess model quality using residuals, leverage, Cook's distance, and Variance Inflation Factor (VIF).
1. Clinical research example

Research question: Which clinical factors are associated with systolic blood pressure (SBP) among adult patients?
We will build a multiple linear regression model to investigate the association between:

    Age
    Body Mass Index (BMI)
    Total cholesterol
    Fasting blood glucose
And the outcome:
- Systolic blood pressure (mmHg)
